The Mandala Experience 
Group 10 - Neha Beru, Utkarsh Dalmia 

A dynamic mandala-based visualizer synced to music using Unity.

How to Run the Project in Unity
Download and unzip the project folder (or clone the repository using the link- https://github.com/nehaberu/MusicViz.git
Open Unity Hub.
Click “Open” and select the unzipped project folder.
Make sure you're using Unity version 2022.3.52f1

Once the project opens:
Open the main scene (usually in Assets/Scenes/)
Click the Play button in the Unity Editor to run the visualization.

Features
8 emotional phases: Emergence, Curiosity, Buildup, Peak, Descent, Resolution, Reflection, Meditation
Mandala visuals respond to real-time audio (song or microphone input)
Customizable visuals using shaders, glow effects, and animations
